# Day 02 - Variables, Data Types and Operators

## Objective

Understand how to use variables, different data types, user input, type conversion, and arithmetic operators by solving simple Python programming problems.

## Topics Covered

- Variables
- Data Types (`int`, `float`, `str`, `bool`)
- User Input using `input()`
- Type Conversion using `int()`
- Arithmetic Operators
  - Addition (`+`)
  - Subtraction (`-`)
  - Multiplication (`*`)
  - Division (`/`)
  - Floor Division (`//`)
  - Modulus (`%`)
  - Exponent (`**`)

## Programs Completed

1. Square of a Number
2. Cube of a Number

4. Perimeter of a Rectangle
5. Convert Minutes to Hours
6. Convert Kilometers to Meters
7. Swap Two Numbers
8. Largest of Two Numbers
9. Average of Five Marks
10. Simple Calculator
